----------------------------------------------------------------
3. DETAILED DESCRIPTION
----------------------------------------------------------------
Horizon Tab turns Chrome's default new tab into a calm, personal dashboard.
It loads instantly, asks for almost nothing, and stays out of your way.

What you get

* A live clock with a greeting and today's date.

* Local weather for your area, with condition icons, a description, and
  today's high and low. Data comes from the US National Weather Service.
  You can set custom coordinates in settings or leave the default.

* A search box that uses YOUR default search engine. Horizon never changes
  your search provider and never sends your query anywhere else. Type a
  URL and it navigates instead of searching.

* A shortcut drawer with three sections (Web Search, AI Chat, and Shop).
  Every tile is a plain link that opens that site in a new tab: eight search
  engines, six AI chats, and fourteen retailers are ready out of the box.

* Quick links for the sites you actually open, with editable icons.

* Five themes, including a custom two-color theme and a day/night adaptive
  one; your own background image with automatic dim and blur; adjustable
  glass intensity; and a global text color override.

Keyboard friendly: press / or Cmd+K to jump to the search box, ? to open
settings, and Esc to close.

Privacy

* No accounts, no sign-in, no analytics, no ads, no tracking.
* Settings stay in your browser profile and sync through your own Chrome Sync.
* The only network requests are the weather lookup and the favicon service
  used for quick-link icons. Searches are ordinary navigations to the engine
  you already chose in Chrome.

Horizon is open source. The code is on GitHub, and it asks for just two
permissions: storage and search.

6. PERMISSION JUSTIFICATIONS
----------------------------------------------------------------
Paste each one into the matching field on the Privacy practices tab.

storage
  Saves your preferences (theme, background image, quick links, weather
  coordinates, drawer state) locally and syncs them through Chrome Sync so
  they follow your profile. This data never leaves the browser and is never
  sent to the developer.

search
  Lets the search box run your query through your browser's own default
  search engine using the Chrome Search API. This is what guarantees the
  extension never changes, replaces, or overrides your search provider.


----------------------------------------------------------------
7. REMOTE CODE
----------------------------------------------------------------
No. All code is bundled in the package. There are no remote scripts, no
eval or new Function, and nothing is fetched and executed at runtime.

10. IF A REVIEWER ASKS ABOUT THE OLD VIOLATION
----------------------------------------------------------------
Say this: the earlier submission bundled a multi-engine search switcher
into the new tab page, which the single purpose policy flags. This build
removes that entirely. Search now runs through the Chrome Search API on
the user's own default engine, the drawer contains only plain links that
open in a new tab, and there are no bangs, filters, custom search sources,
or content scripts. The two remaining permissions are storage and search,
and there is no remote code.
